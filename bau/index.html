Como usarbaixar o script, configurar e rodar
1. BaixeBaixe bau.py e bau.bat para uma pasta. Precisa do Python 3 instalado (marque "Add Python to PATH").
2. RodeNo Windows, dê dois cliques em bau.bat. Em outro sistema: python3 bau.py.
3. ConfigureNa primeira vez ele pede: conta com número (ex.: Nome#1234), liga, POESESSID e quais abas ler. Para mudar depois: bau.bat --config.
4. Veja aquiEle cria snapshots/latest.json e history.json. Arraste os dois nesta página. Rode de novo depois de cada sessão de farm para ver o histórico.
Como pegar o POESESSIDpasso a passo no navegador
  1. Abra pathofexile.com logado na sua conta.
  2. Aperte F12 (ou botão direito na página → Inspecionar).
  3. Clique na aba Application (Aplicativo em português). Se não aparecer, clique em ». No Firefox, a aba é Armazenamento.
  4. Na esquerda: Cookies → https://www.pathofexile.com.
  5. Clique na linha POESESSID, dê dois cliques no Value e aperte Ctrl+C. São 32 letras e números. Se não selecionar tudo, copie do quadro "Cookie Value" embaixo.
  6. No script, cole com Ctrl+V (no cmd antigo, botão direito) e aperte Enter. O texto não aparece ao colar; o script confirma mostrando só o começo e o fim.

O console (document.cookie) não mostra o POESESSID: ele é um cookie protegido. Use a aba Application.

Segurança: o POESESSID é o cookie de login do pathofexile.com (F12 → Application → Cookies → POESESSID). Ele dá acesso total à sua conta. O script guarda só no seu computador (arquivo bau_config.json, se você aceitar salvar) e só manda para o site da GGG. Nunca cole o POESESSID em sites ou mande para outra pessoa. Se achar que vazou, saia da conta no site da GGG: isso invalida o cookie.

Abas especiais de Mapas e de Uniques não são lidas por este acesso. Preços do poe.ninja; itens raros e bases não têm preço automático.
